## 알려진 제약

- 45장 / 20분 = 장당 약 26초. 섹션 표지·한문장 슬라이드가 12장이라 실제 체감은 더 여유롭지만,
  시간이 빠듯하면 03부 경쟁사 파트(23~26)를 2장으로 줄이는 게 가장 안전하다.
- 폰트는 CDN Pretendard. 오프라인 발표면 PDF를 쓴다.
